# Numerical methods

## Sparse exact recurrence

The exact coefficient generator stores each coefficient of the relative-gauge Laurent series as a Python integer.  It builds `D = r d/dr log Z` from the four oscillator families and solves the formal recurrence in increasing R.  Division by R is exact; a failed exact division is treated as an implementation error.

The Haar projection uses the symmetry of the relative U(2) integrand:

`c_(R,S) = [z^0]Z - [z^1]Z`.

This avoids numerical gauge integration in the exact low-q calculation.

## Fixed-Q crossing

At fixed Q we compare

`log d[J,Q]`

with

`log d_sp(2J+Q)`.

The crossing is interpolated linearly in the log mismatch between adjacent discrete 2J values.  The vertical-mismatch analysis uses a local cubic spline only to estimate a derivative at the analytic nonlinear-constraint point.

## High-spin rectangular grading

Since

`R = 3(2J+Q)` and `S=3Q`,

`n=(R-S)/3=2J`.

Two oscillator families contain n=0 modes; these are first absorbed into the `n=0` charge polynomial.  The remaining product is generated by a logarithmic-derivative recurrence in n.

For high n, the relative gauge projection can be evaluated by a trapezoidal Fourier grid in the gauge angle.  The production runs increased the Fourier resolution in the high-Q bands and retained only digits stable under that increase.

## Error diagnostics

The repository distinguishes:

- absolute coordinate residual `2J_cross-2J_ctr`,
- relative residual `2J_cross/2J_ctr-1`,
- continuous wrapped phase residual `Q_ctr(2J_cross)-Q mod 2`,
- vertical log mismatch `Delta_log`,
- slope `d(log d-log d_sp)/d(2J)`.

These quantities answer different asymptotic questions and should not be conflated.
